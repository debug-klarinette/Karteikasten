# Fixed Income · VL 02 – Zinsstrukturkurve & Duration

### Eine inverse Zinsstrukturkurve bedeutet, dass …
- [ ] kurzfristige Zinsen unter den langfristigen liegen.
- [x] kurzfristige Zinsen über den langfristigen liegen.
- [ ] alle Laufzeiten denselben Zins haben.
- [ ] die Forward Rates negativ sind.
> Invers = fallende Kurve: kurze Laufzeiten rentieren höher als lange. Historisch gilt sie als Frühindikator für Rezessionen, da der Markt sinkende Zinsen erwartet.

### Welche Aussagen zur Macaulay-Duration sind korrekt? (Mehrfachauswahl)
- [x] Sie ist der barwertgewichtete durchschnittliche Zahlungszeitpunkt der Anleihe.
- [x] Bei einer Nullkuponanleihe entspricht sie genau der Restlaufzeit.
- [ ] Sie steigt, wenn der Kupon der Anleihe steigt.
- [ ] Sie wird in Geldeinheiten (z. B. Euro) gemessen.
> Höhere Kupons verlagern Zahlungen nach vorne und senken die Duration. Die Macaulay-Duration wird in Jahren gemessen; nur bei Zerobonds gilt Duration = Laufzeit.

### Die Modified Duration einer Anleihe beträgt 6,5. Der Marktzins steigt um 20 Basispunkte. Wie verändert sich der Anleihekurs näherungsweise?
- [ ] +1,30 %
- [ ] −0,65 %
- [x] −1,30 %
- [ ] −6,50 %
> ΔP/P ≈ −MD · Δy = −6,5 · 0,002 = −1,3 %. Die Modified Duration ist die (lineare) Zinssensitivität des Kurses.

### Warum unterschätzt die Duration die Kursänderung bei großen Zinsbewegungen?
- [x] Weil die Preis-Zins-Beziehung konvex ist und die Duration nur die lineare Näherung erfasst.
- [ ] Weil die Duration nur für Nullkuponanleihen definiert ist.
- [ ] Weil Kuponzahlungen bei Zinsänderungen ausfallen können.
- [ ] Weil die Duration in Prozent statt in Jahren gemessen wird.
> Die Konvexität wirkt für den Anleger günstig: Kursgewinne bei sinkenden Zinsen fallen größer, Verluste bei steigenden Zinsen kleiner aus, als die Duration allein anzeigt.

### Welche Theorie erklärt eine normal (steigend) verlaufende Zinsstrukturkurve mit einer von Anlegern geforderten Prämie für lange Bindung?
- [ ] Erwartungstheorie (reine Form)
- [x] Liquiditätspräferenztheorie
- [ ] Marktsegmentierungstheorie
- [ ] Kaufkraftparitätentheorie
> Nach der Liquiditätspräferenztheorie verlangen Anleger für längere Laufzeiten eine Liquiditätsprämie – die Kurve steigt selbst dann, wenn keine Zinserhöhungen erwartet werden.
