# Fabrikplanung · VL 04 – Structure and layout planning

### What is the correct sequence of the structure and layout planning process?
- [ ] Detailed layout planning → rough layout planning → structure planning
- [x] Structure planning (plant/facility structure) → rough layout planning (area structure) → detailed layout planning (resource structure)
- [ ] Rough layout planning → structure planning → detailed layout planning
- [ ] Structure planning → detailed layout planning → rough layout planning
> Explanation: Planning proceeds from coarse to fine: structure planning designs the building arrangement, rough layout planning arranges operating areas within buildings, and detailed layout planning positions the individual resources (machines, connections). Each level runs ideal → real planning with evaluation/selection, and iterations are possible.

### What is the role of the target system in structure and layout planning?
- [ ] It fixes the final machine positions before any analysis
- [x] It specifies the criteria the planned factory should meet, so that alternatives generated in each phase can be compared and the best one selected
- [ ] It replaces the need to analyze the production program
- [ ] It lists only the legal building regulations
> Explanation: The target system is created before planning starts. It defines (often hierarchically structured, quantified where measurable) requirements/criteria, enabling systematic evaluation of alternatives — and its ranking/weighting later feeds directly into the utility analysis in the evaluation phase.

### What characterizes the "ideal functional scheme" (ideal functional layout)?
- [x] Areas are arranged neglecting constraints to achieve the shortest possible paths (material flow usually prioritized); it contains no info on size, shape or real arrangement
- [ ] It is the final, dimensioned floor plan ready for construction
- [ ] It fixes exact machine coordinates and utility connections
- [ ] It only shows the legal boundaries of the property
> Explanation: The ideal functional scheme arranges areas without restrictions for shortest people/material/information paths (material flow having highest weight). It carries no size/shape/real-arrangement data; its purpose is to serve as an ideal benchmark against which later real plans are judged.

### A mechanical-engineering department will employ 40 workers. Using the rough key figure of a mean of 30 m²/employee, what area should be reserved?
- [ ] ≈ 800 m²
- [x] ≈ 1200 m²
- [ ] ≈ 400 m²
- [ ] ≈ 2000 m²
> Explanation: Rough area determination uses key figures such as area/employee. 40 employees × 30 m²/employee = 1200 m². (Ranges are literature values, e.g. 20–50 m²/employee for mechanical engineering; the mean gives a first estimate for the rough phase, refined later at workstation level.)

### Which statement about the three main building structures is correct?
- [x] Multi-story buildings need little land and retain heat well, but force a vertical material flow and limit span width/ceiling load
- [ ] Flat buildings require the least land of all three types
- [ ] Hall buildings are unsuitable for heavy production equipment
- [ ] Multi-story buildings offer the best expansion possibilities
> Explanation: Multi-story buildings save land and heating cost but impose vertical material flow and constraints on span/ceiling load. Flat and hall buildings offer good expansion and clear/large production flow but need more land and more heating; halls allow great heights and heavy loads (steel, foundries, presses).

### How is a transport matrix structured for analyzing transport relationships?
- [ ] It lists only the machines, without any flow quantities
- [x] Each unit in the material flow appears once as sender (row) and once as receiver (column); the cells hold the transport quantities between units per period
- [ ] It records the monetary cost of each machine
- [ ] It shows only the legal distance requirements between areas
> Explanation: In the transport (from-to) matrix every unit is both a source and a sink; each cell gives the transport quantity (weight, pieces, containers, batches) between two units in a period. It is the systematic basis for further layout planning, especially with many units, and strong relationships can be highlighted.

### How do the Sankey diagram and the quantity-path diagram differ?
- [x] The Sankey diagram is a non-scale ideal representation (arrangement not real); the quantity-path diagram maps flows onto a real/planned layout to reveal deficiencies
- [ ] Both are always drawn to real scale on the actual layout
- [ ] The Sankey diagram shows real distances; the quantity-path diagram is schematic
- [ ] They are two names for the same diagram
> Explanation: In both, arrow thickness is proportional to transport quantity. The Sankey diagram uses a non-scale ideal arrangement to highlight dependencies early; the quantity-path diagram is drawn on the real layout to uncover improvement potential — but becomes cluttered when many flows overlap.

### What does the mathematical "Facility Layout Problem" optimize, and how is transport volume computed?
- [x] It minimizes total transport volume, computed as the sum over all pairs of (transport intensity × transport distance), subject to constraints such as available space
- [ ] It maximizes the number of machines per square meter regardless of flow
- [ ] It minimizes only the number of buildings, ignoring material flow
- [ ] It maximizes transport distances to reduce congestion
> Explanation: The objective function minimizes Z = ΣΣ tᵢₗ · dⱼₖ · xᵢⱼ · xₗₖ, i.e. transport intensity times distance summed over all object-location assignments. Costs are assumed proportional to distance and relationship intensity; typical constraints are available space, load capacities, utilities, room heights.

### Machine 4 is placed at position 2 and machine 9 at position 6. The distance d(2,6) = 23 m and the material-flow intensity t(4,9) = 200 pieces/day. What is the resulting transport volume between the two machines?
- [x] 4600 m·pieces per day (200 × 23)
- [ ] 223 per day (200 + 23)
- [ ] 8.7 per day (200 ÷ 23)
- [ ] 2300 per day (100 × 23)
> Explanation: Transport volume = intensity × distance = 200 pieces/day × 23 m = 4600 (meter·pieces) per day. Summing this product over all machine pairs gives the objective value Z that the layout optimization tries to minimize.

### Why are heuristic methods often preferred over complete enumeration for layout optimization? (Consider: 10 machines on 10 locations)
- [x] Because complete enumeration explodes combinatorially — 10 machines on 10 locations already give 10! = 3,628,800 arrangements — while heuristics give good solutions with far less computational effort
- [ ] Because heuristics always guarantee the mathematically optimal layout
- [ ] Because enumeration cannot represent the objective function at all
- [ ] Because heuristics need no objective function
> Explanation: Assigning 10 machines to 10 locations yields 10! = 3,628,800 possibilities (complete enumeration), and the effort grows factorially with size. Heuristics use the same objective function to reach good solutions cheaply, at the cost of limited insight into how optimal the result truly is (field: Operations Research).

### In the graphical triangle method (Schmigalla) and circle method (Schwerdtfeger), how does one begin/proceed?
- [x] Place the unit with the largest total transport relationship first, then successively add the units with the strongest connection to those already placed (trial and error, based on experience)
- [ ] Place units alphabetically and never move them
- [ ] Fix all units by solving a linear program to optimality
- [ ] Arrange units randomly and keep the first result
> Explanation: Graphical methods approach a good solution by trial and error using the planner's experience. Schmigalla's triangle grid starts with the unit having the largest total transport relationship, then adds units with the highest intensity to those already placed; Schwerdtfeger's circle method rearranges units on a circle so intense relationships lie close and don't cross the circle. Both yield an ideal layout to be adapted to constraints.

### How is the transition "from ideal layout to block layout" made, and what is the result?
- [ ] The ideal block layout is always implemented unchanged, even in brownfield projects
- [x] The ideal block layout (optimal arrangement respecting area requirements) is adapted to structural constraints; several variants are generated and the best is chosen, yielding a realizable but not yet fully detailed "rough layout"
- [ ] The block layout skips the detailed layout phase entirely
- [ ] The block layout ignores the space requirements of the areas
> Explanation: The ideal block layout arranges functional areas optimally while respecting their space needs. In greenfield it can be implemented directly; usually it must be adapted to structural constraints (existing buildings). Because the ideal is rarely reached, multiple variants are made and evaluated, producing the rough layout that is then detailed further.

### Match the production-structuring principle to its typical form. Which pairings are correct? (Mehrfachauswahl)
- [x] Function-oriented ↔ workshop production, grouping similar processes (good for diverse products with very different processes)
- [x] Product-oriented ↔ flow production with a dedicated line per product (process-optimal but hard to convert)
- [x] Process-oriented ↔ grouping products into families with similar process sequences, each with a material-flow-efficient area
- [ ] Function-oriented ↔ a single dedicated line per individual product
> Explanation: Function-oriented (workshop) production groups similar techniques/processes and suits varied products with differing processes, prioritizing synergies over material flow. Process-oriented forms product families with similar sequences and lays each out flow-efficiently. Product-oriented mirrors the product range with a dedicated, process-optimized line per product that is hard to reconfigure.
